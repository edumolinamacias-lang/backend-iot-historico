# diagram.json

Este archivo describe el circuito (ESP32 + DHT22) tal como se ve en Wokwi.
No se incluye aquí porque depende de tu proyecto específico. Para exportarlo:

1. Abre tu proyecto en https://wokwi.com
2. Ve a los tres puntos (⋮) en la esquina superior del editor → **Download files** (o **Export**)
3. Descarga `diagram.json`
4. Colócalo en esta misma carpeta (`wokwi/diagram.json`), junto a `sketch.ino`

Una vez agregado, borra este archivo (`DIAGRAM_README.md`) o consérvalo como referencia.
